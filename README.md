# PictureBook

Transform your stories into picture books.

## Features

- **Two Creation Modes**: Start from text (AI generates pages) or blank template (manual creation)
- **AI-Generated Images**: Illustrations using Stable Diffusion XL
- **Interactive Editor**: Easy-to-use page editor with text and image management
- **PDF Export**: PDF generation of books for printing and sharing
- **Privacy Controls**: Public/private book settings with shareable URLs
- **Google Authentication**: Secure sign-in with Supabase Auth

## Tech Stack

- Next.js
- Tailwind CSS
- Supabase (Database, Auth)
- Google Generative AI (Gemini 2.0 Flash)
- Stable Diffusion XL
